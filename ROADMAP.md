# Roadmap

## Done
- Multi-game host with a module registry and shared rooms (codes, capacity, idle expiry), one cartoon design and no CSS framework.
- Chess: legal-move board, promotions, Ralf played by an LLM (Azure AI Foundry) with legal-move validation and retries, remote battle, FEN/UCI/SAN log, PGN/JSON export, snapshots on disk.
- Developy: complete rules (purchase, fees, groups, teams and architects, clouds, events, AI tokens, meeting, Hackathon pot, Tech Debt, freezing and selling, bankruptcy, hostile takeover, round limit with valuation), server-side bots, hot-seat and remote seats, chat, rotating 3D board, identity that survives a refresh.
- Image and asset optimisation; build output kept outside the repo.

## Next
- Developy: trades between players, auctions for declined projects, an end-of-game summary saved to disk, sounds (the prototype had a sound button).
- Shared: persistent identities, rejoining from another device, a list of the host's rooms, rate limits.
- Chess: clock, resignation and draw offers, a stronger engine with difficulty levels.
- New modules on the same contract: territory conquest, deduction with secret cards.
- Browser end-to-end tests in CI, production deployment behind HTTPS.
